# 2001 Nails of Woodbury logo system

## Assets

- `logo-primary.svg` / `logo-primary.png` — transparent primary mark for the website, print, signage, and gift cards.
- `logo-favicon.svg` / `logo-favicon.png` — compact square mark that retains the complete `2001` name at small sizes.
- `logo-transition.svg` / `logo-transition.png` — reversed mark on the olive brand field for video and screen transitions.
- `logo-system-preview.svg` / `logo-system-preview.png` — presentation board showing the three marks together.

The production logos are hand-authored SVG artwork with no external font or design-library dependency. Keep the artwork proportions intact and leave clear space around the diamond and wordmark.

## Colors

- Olive: `#4F5A42`
- Cream: `#FFFAF2`
- Brass: `#B08B5B`
- Soft brass: `#D9C7AA`
- Charcoal: `#302D28`

## Source

The production SVG files are the editable masters. All letters and numerals are constructed from native SVG paths and shapes.
